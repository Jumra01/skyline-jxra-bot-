FOTO BASE — fitur `.pap` / Ella2
================================

Taruh foto base di folder ini. Tiap ada yang minta foto, satu foto diambil
ACAK dari sini, terus diedit AI (Omni Editor) sesuai permintaan orang yang
ngobrol — contoh: "pake baju merah, latar kafe", "gaya selfie di pantai".

Aturan:
• format: jpg / jpeg / png / webp / gif
• maks 10 MB per file
• taruh langsung di folder ini (tanpa subfolder)
• folder kosong → bot bilang "Belum ada foto base nih"
• ganti isi folder kapan aja — gak perlu restart, dibaca tiap request

Kenapa asset lokal (bukan cari di Pinterest)?
Hasil pin kadang kena sensor / gak nyambung sama maksud. Foto base dikontrol
penuh dari folder ini.
